> In a city bleached of all creativity by the beige bureaucracy of The Company, one artist has had enough. Lace up your skates, crank up the volume, and get ready to shatter the monochrome monotony.
>
> Inspired by movement-based games like *Jet Set Radio*, *Tricks On It* is a high-speed, third-person action game where style is your weapon. As a rebellious rollerskater, you’ll grind rails, leap across rooftops, and string together dizzying aerial combos to build up your Flow. This raw creativity is your ammunition—unleash it as powerful attacks to shatter the gray-suited, lifeless businessmen who enforce the city's oppressive stillness.

## Controls

#### Keyboard & Mouse

| Action                 | Key                       |
| ---------------------- | ------------------------- |
| **Movement** | `WASD`                    |
| **Camera** | `Mouse`                   |
| **Jump / Wall Jump** | `Spacebar`                |
| **Sprint / Dash** | `Left Shift`              |
| **Melee Attack** | `Left Mouse Button`       |
| **Aim / Ranged Attack**| `Right Mouse Button (Hold)` |
| **Air Tricks** | `Q / E / R / F`           |
| **Pause Game** | `Escape`                  |

## Installation

1.  Download the latest release from the [Releases Page](https://github.com/TMarwah/TricksOnIt/releases).
2.  Unzip the folder.
3.  Run `TricksOnIt.exe`.
